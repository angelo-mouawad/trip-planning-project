## UI design and Features

#### Home tab:

- listing
- Place Recommendation (using ratings and friends)
- Friends updates
- Notifications / alerts

#### Friends:

- see public trips
- see ratings
- Pics / moments
- friends suggestion

#### Trips/map:

- get a fullscreen sized map
- at the top have a selection of:
  - Individually premade trips
  - All places that i liked
  - All places that i want to go to
  - visible pins are colored based on the type of place (diner/cafe/activity/...)
  - Filter based on Type, Group, Price?

#### Account:

- Settings
- privacy
- looks
- account details
- subscription (IDK what but we need money)
- notification
- Report (if there is a bug in the app)
- Logout

#### Create trip:

- You search for the place like a normal map
- when the location is pressed, a menu pop up containing:
  - details
  - ratings
  - friends that's been there
  - buttons (add to list, add to trip)
- There are recommendations based on the type (like google maps)

#### Important notes:

can’t rate unless visited (can use gps tracking while opening the app, we can track gps only when trip is active but that will eliminate the option where the user was there before using the app making it annoying)
Privacy is a huge thing because other users can see the person’s public life. So we need to make by default things private (account, already done trip, moments/pics) and asking if they are sure when setting them public (publicity is done individually, meaning each trip has its own visibility and not a global setting )
Respectable reviews and a reporting system
There are no following system only friend, both parties should agree on seeing each others activity
blocking systems
account suggestion based on phone nb / google account.
when someone is invited to a trip they should accept the invitation
For fun we can implement roles for each group trip members (driver, dj, snack supplier, “im here for the vibes” for the useless guy)
when the trip begins all participants will receive a notification, and there live location will be shared. whenever someone opens the trip’s map, they can see everyones location, grouping the users that are close to each other. A text chat will also be available.
