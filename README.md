# Trip Planning Project

## Description

Save the places you want to visit, add notes, and turn your pins into routes.

Most of us keep a list of places somewhere: screenshots, a note on the phone, a saved reel, a message you sent yourself. It never turns into an actual trip because the list and the map live in different places. pindrop puts them together.

## What it does

**Pin places.** Search for a spot, drop it on the map, add a note about why you saved it. "Good coffee, opens at 7" is more useful six months later than a bare marker.

**Build routes.** Pick a few pins and pindrop orders them into a route that makes sense geographically, so planning a day out takes a minute instead of an evening.

**Rate what you've been to.** Once you visit a place, rate it. Your ratings feed the recommendations.

**Get recommendations.** Based on the places you saved and liked, pindrop suggests new ones. If you keep saving quiet bookshops and small wine bars, it stops sending you rooftop clubs.

**Plan with friends.** Create a group, everyone brings their own saved places, and pindrop blends the lists into a shared trip. You see where your interests overlap and where you need to compromise.
